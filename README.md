# Grid Tanks

Маленькая пошаговая стратегия про танки (кооператив).

Захватывайте территорию, покупайте танки и попробуйте уничтожить базу противника.

## Запуск

Зависимости: 
_python3_

библиотеки: 
_pygame_ 
_numpy_

Для запуска введите команду _python -m src.main_

Установка библиотек:
```
python3 -m venv .venv

source ./.venv/bin/activate  # на Ubuntu

pip install pygame numpy
```
