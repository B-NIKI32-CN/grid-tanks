# Grid Tanks

Маленькая пошаговая стратегия про танки (LAN PvP).

Захватывайте территорию, покупайте танки и попробуйте уничтожить базу противника.

## Запуск

Зависимости: 
_python3_

библиотеки: 
_pygame_ 
_numpy_

Для запуска введите:
```
python -m src.main  # windows

python3 -m src.main  # linux
```

Установка библиотек:
```
python3 -m venv .venv

source ./.venv/bin/activate  # на Ubuntu

pip install pygame numpy
```
